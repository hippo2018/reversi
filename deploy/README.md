# レンタルサーバーへの設置

## 動作条件

- PHP 8.1以上、PDO_SQLite拡張が利用できること。
- PHPから書き込み可能な、公開ディレクトリ外の保存先があること。
- 同梱の `.htaccess` はApache 2.4互換サーバー向けです。他のサーバーでは対応するアクセス制限を設定してください。
- サーバー側のNode.js、npm、常駐プロセスは不要です。

## アップロード

1. 管理画面でPHP 8.1以上とSQLite拡張を有効にします。
2. `storage` フォルダーを公開ディレクトリの外にアップロードします。
3. `public/config.php` の `REVERSI_DATA_DIR` を、その保存先のサーバー上の絶対パスに合わせます。例: `define('REVERSI_DATA_DIR', '/home/account/reversi-storage');`
4. `public` の **中身すべて** を公開先（例: `public_html/` または `public_html/reversi/`）へアップロードします。FTPソフトで隠しファイルの `.htaccess` も含めてください。
5. 保存先をPHPから書き込み可能にします。権限は契約サーバーの推奨値に従ってください。通常は所有者を合わせて700または755を使い、777にはしません。
6. `https://example.com/` または `https://example.com/reversi/` を開きます。サブディレクトリのURLは末尾に `/` を付けてください。
7. 新しい対局と着手を確認します。SQLiteデータベースは初回アクセス時に自動作成されます。

公開先が `/home/account/public_html/`、保存先が `/home/account/storage/` の構成なら、同梱の設定をそのまま使えます。サブディレクトリに設置する場合は必ず保存先を変更し、`storage` が公開ディレクトリ内に入らないようにしてください。

既存サイトがある場合は専用サブディレクトリに設置し、既存の `index.html` や `.htaccess` を上書きしないでください。

## 更新・トラブル対応

- 更新時は `assets/` とPHPファイルを先に、`index.html` を最後にアップロードします。
- 更新時もサーバーで変更した `config.php` と `storage` は保持します。開発用の対局データは配布物に含まれません。
- 500エラーはサーバーのPHPエラーログで確認してください。SQLite拡張、保存先のパスと書き込み権限を確認します。
- APIは画面と同じURL配下を使用するため、通常は `VITE_API_BASE` やCORS設定の変更は不要です。
- このゲームにはログインや対局ごとのアクセス制御はありません。機密データの保存には使わず、必要に応じてサーバー側でアクセス制限を設定してください。
